# LearnPilot

Chrome / Edge Manifest V3 扩展，提供学习通课程连续播放、题目资料检索、临时题库，以及限定到当前课程会话的授权测试模式。

## 功能

- 当前视频真实播放结束后，寻找并进入下一节。
- 支持 1×、1.25×、1.5×、2× 播放速度和实时播放进度。
- 扩展弹窗提供独立“网课助手”，可直接设置当前标签页的倍速、完成后跳转和自动答题状态。
- 记录当前会话中正常播放完成并切换的章节数量。
- 所有普通 HTTP/HTTPS 网页默认只显示右侧悬浮入口，侧边栏不会在页面载入时自动展开。
- 选中网页文字后就近显示“AI 解析”，一键检索当前选区。
- 读取当前可见题目或用户选中的文字。
- 临时题库精确/相似匹配，未命中时调用联网搜索与大模型。
- 提供手动 AI 问答入口，不依赖页面题目结构。
- 临时题库可进入背题模式，逐题隐藏/显示答案和解析。
- 显示建议选项、解析、置信度、警告和来源。
- 为当前课程点击一次开启测试模式后，可按阈值勾选并进入下一题。
- 遇到低置信度、来源冲突、题型无法映射或最终提交时停止。
- 不保存题目历史或错题本；临时题库和授权状态保存在浏览器会话中。

## 安装

要求 Node.js 20 或更高版本。

```powershell
npm install
npm run check
```

然后打开 Chrome 或 Edge 的扩展管理页面：

1. 开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本项目的 `dist` 目录。
4. 固定“LearnPilot”扩展图标。

首次从旧版本升级到全网页版本时，浏览器会提示该扩展可读取和更改网站数据；这是常驻入口和划词分析所需权限。浏览器内部页面、扩展商店和新标签页禁止内容脚本注入，因此不会显示悬浮入口。

修改源码后重新运行 `npm run build`，再到扩展管理页点击刷新。

界面采用暖白与浅米色结构、低饱和蓝灰操作色，并在侧栏、扩展弹窗、设置页和演示页中保持一致。

## 模型配置

点击扩展图标，再打开“模型设置”：

- `API Base URL` 填接口根地址，例如 `https://api.openai.com/v1`。
- 选择 `Responses API` 或 `Chat Completions`。
- 填写服务商提供的准确模型 ID 和 API Key。
- 点击“测试模型连接”。

DeepSeek 预设使用 Responses API、`deepseek-v4-flash` 与官方 `web_search` 工具；点击“测试模型连接”会真正触发一次联网搜索并检查接口返回的搜索调用记录。OpenAI 使用对应的 Responses 网页搜索格式。其他兼容服务如果不支持内置搜索，可切换到 Tavily，或者关闭搜索仅使用模型。DeepSeek 请求格式参照[官方 Responses API 文档](https://api-docs.deepseek.com/api/create-response/)，OpenAI 请求格式参照[官方网页搜索文档](https://developers.openai.com/api/docs/guides/tools-web-search)。

密钥默认只保存在当前浏览器会话。若选择本机保存，密钥会存入扩展的 `chrome.storage.local`；浏览器扩展无法为它提供硬件级保护。

## 临时题库格式

支持 `.xlsx`、`.csv`、`.tsv`、`.txt` 和 `.json`。旧式 `.xls` 不解析，请先另存为 `.xlsx`。

表格至少需要“题目”和“答案”两列，也支持以下列名：

```text
题目 | A | B | C | D | 答案 | 解析 | 来源
```

答案可以是 `A`、`AC`、`正确`，也可以直接填写选项文本。可从 [examples/question-bank.csv](examples/question-bank.csv) 开始编辑。

JSON 可以是数组，也可以是 `{ "questions": [...] }`：

```json
[
  {
    "question": "计算机中最小的数据单位是什么？",
    "A": "位",
    "B": "字节",
    "answer": "A",
    "explanation": "位是最小的数据单位"
  }
]
```

## 使用

### 连续播放

可在扩展弹窗的“网课助手”中选择倍速与“完成后自动跳到下一节”，也可在课程页面侧边栏点击“开启连续播放”。当前视频触发真实 `ended` 状态后，扩展会寻找“下一节”按钮或目录中的下一项。遇到题目、签到、验证码、登录提示或课程末尾会停止。

浏览器可能阻止带声音的自动播放；这种情况下手动播放一次当前视频即可。扩展不会拖动进度、伪造播放时长或处理验证码。

### 分析题目

优先在页面选择完整题干和选项，然后点击“分析当前题目”。未选择文字时，扩展会通过页面 DOM 规则寻找当前可见题目。

### 授权测试模式

1. 在你自己创建或获授权测试的课程中，打开“当前课程测试模式”。
2. 点击“开始自动分析、勾选与翻题”。
3. 结果达到设置的置信度阈值且没有警告时，扩展才会操作选项。
4. 最终提交按钮不会被点击，必须由你检查后亲自提交。

授权状态只对自动识别出的当前课程 ID 生效，并在浏览器关闭后清除。

## 本地演示

从扩展弹窗打开“演示题页”。它使用和页面适配器相同的题目 DOM，可在不访问真实课程的情况下测试临时题库、分析、自动勾选和翻题。

## 页面兼容与诊断

学习通页面存在多个版本，扩展采用通用选择器和可见区域启发式识别。若提示“没有识别到题目”：

1. 选中题干和全部选项后重新分析。
2. 确认扩展设置中的模型连接测试成功。
3. 刷新课程页，使最新内容脚本加载。
4. 在演示题页确认核心流程工作正常。

页面结构更新时，主要调整 `src/content/question.ts` 和 `src/content/playback.ts`，模型与界面无需改动。

测试版还可以在侧栏“显示”菜单中点击“导出诊断包”。诊断 JSON 会汇总顶层页面和最近活动 iframe 的任务信号、播放器状态、题目摘要及简化 DOM，不包含输入框内容、Cookie、密码、API Key 或完整查询参数。反馈兼容问题时可附上该文件。

## 隐私与边界

- 只有点击分析或开启测试模式后，题目才会发送到配置的模型/搜索服务。
- 题目、搜索结果、临时题库和课程授权状态不做长期保存。
- 不读取账号密码，也不主动收集 Cookie。
- 页面和搜索资料均作为不可信数据处理，不能覆盖模型系统指令。
- 自动测试只应在自己创建或明确获授权的课程中开启。
- 最终提交、验证码和平台限制不由扩展处理。

## 自动版本发布到 Git

首次使用前配置远程仓库：

```powershell
git remote add origin <你的 Git 仓库地址>
git push -u origin main
```

以后需要发布新版本时运行：

```powershell
npm run release:patch  # 0.2.0 -> 0.2.1
npm run release:minor  # 0.2.0 -> 0.3.0
npm run release:major  # 0.2.0 -> 1.0.0
```

发布脚本要求工作区干净且已配置 `origin`。它会同步更新 `package.json`、`package-lock.json` 和扩展清单版本，执行完整检查，生成 `release/LearnPilot-版本号.zip`，创建 Git 提交与标签，并推送当前分支和标签。推送失败时提交和标签仍保留在本地，可以排除网络或权限问题后重新推送。
